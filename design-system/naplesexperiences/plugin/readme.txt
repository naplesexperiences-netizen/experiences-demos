Token, componenti e correzioni di contrasto per experiences-theme.

== Description ==

* tokens.css — colori, tipografia, spaziature, raggi, ombre e animazioni come variabili CSS (--exp-*).
* components.css — classi exp-btn, exp-chip, exp-link, exp-card, exp-badge, exp-icon-btn.
* compat.css — corregge i contrasti WCAG AA sui template attuali del tema (home: da 79 a 0 testi sotto soglia). Si attiva solo con experiences-theme.

Non modifica il tema né il database. Disattivandolo il sito torna com'era.

== Installation ==

1. Bacheca → Plugin → Aggiungi nuovo → Carica plugin → scegliere experiences-design-system.zip.
2. Attivare.
3. Svuotare la cache (WP Cloudflare Page Cache: «Svuota cache»), altrimenti i visitatori vedono la versione precedente.
